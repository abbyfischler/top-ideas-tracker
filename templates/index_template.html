How to read this. Each analyst contributes one "top idea" per monthly report. When the ticker is the same as last month, that's a held position and the return shown is the price change since the prior report's cover price. When the ticker changes ("CHANGED" badge), that's a fresh pick — no return is attributed for the switch itself, since the exit price of the abandoned position isn't part of this dataset. All-time and trailing-12-report figures compound only the periods where a position was actually held; they don't reflect a real portfolio, dividends, fees, or slippage.

ETF comparison. Where a sector ETF was supplied, each analyst's detail view shows their actual calendar-year return (compounded from held periods within that year) beside the ETF's full-year return for the same year. This is available for 18 of 47 analysts so far — the rest will show once benchmark data is supplied for that coverage area.

Data corrections applied. Several analyst names were merged where the source file listed the same person under inconsistent labels across reports (credential suffixes, stray sector-name prefixes, or a co-analyst credit) — verified by unbroken ticker continuity across the switch. Five rows with a corrupted PDF-extraction artifact (price populated as a flat "500" alongside garbled company text) were nulled out rather than guessed at. Sector groupings are assigned from each analyst's documented coverage area; a small number of analysts new to this file were classified by their typical pick composition.

Source: Oppenheimer Top Ideas Monthly reports, Jan 2023 – Jun 2026, transcribed into a coverage spreadsheet.
